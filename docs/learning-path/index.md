# GB Studio Learning Path

This learning path complements the reference documentation with a structured, project-driven course. It is designed for people opening GB Studio for the first time, experienced users who want stronger project architecture, and technical contributors who want a guided route into plugins, GBVM, and engine-level work.

The course is intentionally practical. Each chapter combines a mental model, technical context, a guided workshop, common failure modes, an exercise, a mastery check, and links back to the relevant reference pages.

- [Start the Master Course](./course-en)
- [View the full course curriculum](./course-curriculum)

## What the course covers

The path moves from installation and the edit-build-test loop through project organization, scene types, backgrounds, collisions, actors, triggers, sprites, palettes, music and sound, scripting, variables, control flow, reusable systems, debugging, hardware budgets, distribution, plugins, GBVM, and Engine Eject. It finishes with capstone projects and a professional release/contribution workflow.

## How to use it

Do not read the course passively. Open GB Studio and complete the workshop and mastery check in each chapter. When a behavior or limit matters to a project decision, follow the linked reference documentation: the reference docs remain the source of truth for current GB Studio behavior.
