# Gatilhos

Gatilhos são áreas em uma cena que, quando o jogador passa sobre elas, fazem com que um script seja executado. Eles são úteis para criar passagens entre cenas e para iniciar cutscenes quando o jogador se move para uma posição específica.

## Adicionando um gatilho

Para adicionar um gatilho a uma cena, clique no botão **` + `** nas _Ferramentas do editor_ e selecione _Gatilho_ no menu (alternativamente, pressione a tecla **T**). Em seguida, clique e arraste pela cena onde deseja posicionar o gatilho, definindo a largura e a altura desejadas.

<img src="/img/screenshots/add-trigger.gif" style={{width:300}} />

A _Barra lateral do editor_ mudará para mostrar as configurações do gatilho, onde você pode dar um nome ao gatilho para facilitar a navegação posteriormente, reposicionar e redimensionar o gatilho e criar o script que será executado quando o jogador pisar no gatilho.

## Scripts

Quando o gatilho estiver selecionado, clique no botão _Adicionar evento_ na _Barra lateral do editor_ para abrir o menu de eventos e começar a construir o script. Para obter mais informações, veja a documentação de [Scripts](/docs/scripting).
