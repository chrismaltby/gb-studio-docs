# GB Studio Tools

- [GBS Music](https://music.gbstudio.dev)  
  The GB Studio music editor, available as a standalone web app for desktop, tablet, and mobile.

- [GB Flamegraph](https://chrismaltby.github.io/gb-flamegraph/)  
  Drop an exported `.gb` ROM and its `.noi` memory map to generate a flame graph of CPU usage. This can help you identify causes of slowdown.

- [GB Studio Collision Tile Generator](https://chrismaltby.github.io/gbs-collision-tile-generator/)  
  A tool for creating collision tile images for use in the "icon" field in [scene type plugins](/docs/extending-gbstudio/plugins#additional-scene-types).

- [Tessarium](https://www.joeljgames.co.uk/tools/tessarium/)  
  A tile-first pixel art editor for creating GB Studio backgrounds and reusable tilesets. Draw directly on the canvas with gradients, terrain brushes and stamping, and edit linked tiles once to update every copy. Includes GB/GBC palettes, GB Studio font importing, guidance for scene sizes, unique tile counts and colours per tile. Runs in the browser, with free desktop builds for macOS, Windows and Linux. Disclosure: developed with substantial AI coding assistance.
